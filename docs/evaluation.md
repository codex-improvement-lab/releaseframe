# Preview evidence and choice boundary

The Lab previously built a complete [Breakcase alpha.3 launch card](https://x.com/eliasruntime/status/2103110232344019174) with an authored 46-line HTML/CSS/Playwright script, then wrote its ALT and X post separately. This was an actual internal product release task. Its code and screenshots are retained privately in the Lab's research directory, not redistributed as the Releaseframe demo. No complete task-time or model-token comparison was measured.

At a fixed `google/fonts` revision with Inter and `@resvg/resvg-js` 2.6.2, a local prototype rendered the same 375×667 historical input pair into an 1120×780 PNG, 89,748 bytes. It derived failure for the 435px candidate and acceptance for the 385px candidate against a declared 385px plus 1px cap, and wrote ALT, draft and review JSON. The two screenshots and numbers come from one historical Bootstrap reproduction trial, not an external user. The image was visually inspected. The packaged product uses the same narrow input/output contract and additionally has a fully authored demo.

**Existing alternatives.** Shotcraft's public quickstart covers captures from live apps. Visual Factory Kit's source at `e87f4bcf71409ca81a039a6a4ac047d57e107b39` has JSON requests, brand packs, provenance and QA. Its stock `before_after.html` and `product_release.html` at that revision arrange copy/proof labels without slots for two supplied screenshots. It could serve this use case with a custom template. The strongest already-executed route for our exact offline input was the Lab's custom HTML/CSS card, which succeeded. Neither competing product was executed end-to-end in this comparison, so there is no relative runtime or quality ranking.

**What the preview checks.** Source paths are caller-listed; the PNG signature, dimensions, size and pair match are checked before writing. Card strings are escaped, necessary source/caveat fields are required, result badges follow only the declared numeric values, and the output directory is not overwritten. A bundled font makes local rendering independent of installed system fonts. The card may crop a visible window from each source; it remains the Agent's job to inspect that crop. `review.json` stores the exact SHA-256 of each input and rendered image, and says that metric values were declared rather than measured from pixels.

**What remains unknown.** Whether agents will discover or choose Releaseframe; whether one manifest saves net task time against a reusable competitor template; whether humans engage with or understand the images more often; CJK card quality; pixel identity on physical macOS and Linux; and privacy of arbitrary supplied screenshots. Repo CI and a local visual check cannot prove those outcomes.
